# Information Security Policy

## Passwords

Passwords must be at least 14 characters and are rotated every 180 days. Multi-factor authentication is required for all remote access.

## Data Classification

Data is classified as Public, Internal, Confidential or Restricted. Customer payment data is Restricted and must never be stored on local devices.

## Incident Reporting

Suspected security incidents must be reported to the Security Operations Center within 1 hour.
